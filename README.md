# AnonyLink 🔐

Anonymous 1-to-1 Telegram chat bot with:
- Intent-based matchmaking
- One-month global free access
- Free trials after global free
- VIP via Telegram Stars
- PostgreSQL + Redis
- Production-ready architecture

---

## 🚀 FEATURES

- Anonymous chat (no identity leakage)
- Gender / intent matching
- Global free window (Jan 25 – Feb 25)
- Trial-based access after free window
- VIP unlock via Telegram Stars
- Redis-powered matchmaking
- PostgreSQL user persistence
